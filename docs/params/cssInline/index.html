CSS Inline (StyleTag)

The StyleTag enum provides a strongly-typed way to apply inline CSS to your Metafr components. It prevents typos and streamlines the process of styling individual nodes by automatically converting Rust enums to valid CSS properties.

Usage

You can generate CSS declarations using the get_tag method on StyleTag variants. Then, use get_style_inline to combine them into a single style parameter that can be applied to any component.

use metafr::params::style_inline::{StyleTag, get_style_inline};
use metafr::components::typography;

let my_styles = vec![
    StyleTag::Color.get_tag("red"),
    StyleTag::MarginTop.get_tag("20px"),
    StyleTag::Display.get_tag("flex")
];

let title = typography::typography_create()
    .set_text("Styled Title")
    .set_params(vec![
        get_style_inline(my_styles)
    ])
    .build();

Key Features

  • Type-Safe Properties: Access nearly all standard CSS properties (e.g., StyleTag::MarginTop, StyleTag::Display, StyleTag::JustifyContent) as enum variants.
  • Auto-formatting: The enum handles converting CamelCase names into standard kebab-case CSS properties automatically (e.g., MarginTop becomes margin-top).
  • Custom Fallback: If a CSS property isn't listed, you can use StyleTag::Custom("your-property") as a fallback.
