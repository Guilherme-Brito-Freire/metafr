Scope Component

The Scope component is a foundational layout building block in Metafr. It maps directly to an HTML <div> element and acts as a container for other nodes (components).

Usage

To use the Scope component, utilize the builder pattern starting with scope_create().

use metafr::components::scope;
use metafr::components::typography;

let my_scope = scope::scope_create()
    .set_children(vec![
        typography::typography_create()
            .set_text("Child 1")
            .build(),
        typography::typography_create()
            .set_text("Child 2")
            .build()
    ])
    .build();

Methods

  • scope_create() -> Scope: Initializes a new Scope builder with an empty <div> structure.
  • set_children(self, children: Vec<Node>) -> Scope: Sets the child nodes that will be rendered inside this container.
  • set_params(self, params: Vec<Param>) -> Scope: Applies HTML attributes (like class, id, style) to the underlying <div> element.
  • build(self) -> Node: Finalizes the component, rendering children to HTML and returning a generic Node ready to be injected into a Document or another Scope.
