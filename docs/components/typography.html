Typography Component

The Typography component is used for rendering text content in Metafr. Currently, it defaults to mapping directly to an HTML <h1> element, making it ideal for page headings and titles.

Usage

To use the Typography component, instantiate it with typography_create(TypographyType), configure its text, and finally build it into a Node.

use metafr::components::typography::{typography_create, TypographyType::H1};

let title = typography_create(H1)
    .set_text("Welcome to Metafr!")
    .build();

Methods

  • typography_create(typography_type: TypographyType) -> Typography: Initializes a new Typography builder with default text ("Hello World!") and the specified tag (e.g. H1, H2, P, Span).
  • set_text(self, text: &str) -> Typography: Sets the inner text content of the HTML element.
  • set_params(self, params: Vec<Param>) -> Typography: Applies HTML attributes (like class, style, etc.) to the underlying tag.
  • add_class(self, class_str: &str) -> Typography: Appends a CSS class to the element.
  • add_class_from_string(self, class_str: String) -> Typography: Appends a CSS class to the element using an owned String.
  • build(self) -> Node: Finalizes the component and returns a Node that can be rendered or added to a Scope.
