Structure Component

The Structure component allows you to create semantic HTML5 layout tags like <header>, <footer>, <section>, <aside>, and <nav>.

Usage

use metafr::components::structure::{structure_create, StrutureType};

let header = structure_create(StrutureType::Header)
    .set_children(vec![...])
    .build();

Methods

  • structure_create(structure_type: StrutureType) -> Struture: Initializes a new Structure builder for the specified semantic tag.
  • set_children(self, children: Vec<Node>) -> Struture: Sets the child nodes that will be rendered inside this structure.
  • set_params(self, params: Vec<Param>) -> Struture: Applies HTML attributes (like class, id, style) to the underlying element.
  • add_class(self, class_str: &str) -> Struture: Appends a CSS class to the element.
  • add_class_from_string(self, class_str: String) -> Struture: Appends a CSS class to the element using an owned String.
  • build(self) -> Node: Finalizes the component, rendering children to HTML and returning a generic Node.

Styled Components

The Structure component also provides pre-styled variations for common layout needs:

  • nav_styled_create(color: &str) -> Struture: Creates a pre-styled <nav> component with a specific background color, flexbox layout, and standard height/padding.
  • footer_styled_create(color: &str) -> Struture: Creates a pre-styled <footer> component with a specific background color, flexbox layout, and standard height/padding.
