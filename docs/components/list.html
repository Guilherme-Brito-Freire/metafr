List Component

The List and ListItem components are used to create standard HTML lists (<ul>, <ol>, <dl>) and their corresponding items (<li>, <dt>/<dd>).

Usage

To use these components, import list_create and list_item_create along with their types, and build them as part of your component tree.

use metafr::components::list::list::{list_create, ListType};
use metafr::components::list::list_item::{list_item_create, ListItemType};
use metafr::components::typography::{typography_create, TypographyType::Span};

let my_list = list_create(ListType::Ul)
    .set_children(vec![
        list_item_create(ListItemType::Li)
            .set_children(vec![
                typography_create(Span).set_text("Item 1").build(),
            ])
            .build(),
        list_item_create(ListItemType::Li)
            .set_children(vec![
                typography_create(Span).set_text("Item 2").build(),
            ])
            .build(),
    ])
    .build();

Methods (List)

  • list_create(list_type: ListType) -> List: Initializes a new List builder of a specific type (e.g. Ul, Ol, Dl).
  • set_children(self, children: Vec<Node>) -> List: Sets the child nodes (usually ListItems) that will be rendered inside this list.
  • set_params(self, params: Vec<Param>) -> List: Applies HTML attributes (like class, style, etc.) to the underlying list tag.
  • add_class(self, class_str: &str) -> List: Appends a CSS class to the element.
  • add_class_from_string(self, class_str: String) -> List: Appends a CSS class to the element using an owned String.
  • build(self) -> Node: Finalizes the component and returns a Node.

Methods (ListItem)

  • list_item_create(list_item_type: ListItemType) -> ListItem: Initializes a new ListItem builder of a specific type (e.g. Li, Dl).
  • set_children(self, children: Vec<Node>) -> ListItem: Sets the child nodes (content) for this list item.
  • set_params(self, params: Vec<Param>) -> ListItem: Applies HTML attributes (like class, style, etc.) to the underlying list item tag.
  • add_class(self, class_str: &str) -> ListItem: Appends a CSS class to the element.
  • add_class_from_string(self, class_str: String) -> ListItem: Appends a CSS class to the element using an owned String.
  • build(self) -> Node: Finalizes the component and returns a Node.
