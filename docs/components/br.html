Br Component

The Br component provides a simple way to create an HTML <br> element to break the line.

Usage

To use the Br component, simply call the br() function, which directly returns a Node.

use metafr::components::br::br;

let line_break = br();

Methods

  • br() -> Node: Returns a Node representing an HTML line break (<br>).
