CustomTag Component

The CustomTag component provides a flexible way to create any HTML element dynamically by specifying its tag name during initialization. It maps directly to an HTML <{tag}> element with text content inside.

Usage

To use the CustomTag component, utilize the builder pattern starting with custom_tag_create(tag: &str).

use metafr::components::custom_tag;

let my_custom_element = custom_tag::custom_tag_create("button")
    .set_content("Click Me!")
    .build();

Methods

  • custom_tag_create(tag: &str) -> CustomTag: Initializes a new CustomTag builder with the specified HTML tag name (e.g., "button", "span", "article").
  • set_content(self, text: &str) -> CustomTag: Sets the inner text content of the HTML element. If not set, it defaults to a placeholder.
  • set_params(self, params: Vec<Param>) -> CustomTag: Applies HTML attributes (like class, id, style) to the underlying element.
  • build(self) -> Node: Finalizes the component, returning a generic Node ready to be injected into a Document or Scope.
