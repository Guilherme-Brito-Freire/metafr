StyleTag Component

The StyleTag component provides a way to define internal CSS stylesheets within a <style> tag.

Usage

To use the StyleTag component, utilize the builder pattern starting with style_tag_create(), define your rules using create_style_rule(), and apply them with set_style().

use metafr::styling::style_tag::{style_tag_create, create_style_rule};

let my_style = style_tag_create()
    .set_style(vec![
        create_style_rule("h1", vec![
            "color: red;".to_string(),
            "font-size: 24px;".to_string()
        ])
    ])
    .build();

Methods

  • style_tag_create() -> StyleTag: Initializes a new StyleTag builder with an empty <style> element.
  • create_style_rule(rule: &str, modifiers: Vec<String>) -> StyleRules: Creates a new CSS rule mapping a selector (e.g., "*", "h1", ".class") to a list of CSS properties.
  • set_style(self, styles_rules: Vec<StyleRules>) -> StyleTag: Sets the CSS rules inside the style tag.
  • add_class_from_string(self, class_str: String) -> StyleTag: Appends a CSS class to the style element itself using an owned String.
  • build(self) -> Node: Finalizes the component, generating the final CSS text and returning a Node ready to be injected into a Document or Scope.
