Metafr

A minimalistic Rust framework for server-side HTML rendering and routing, built on top of Axum and Tokio.

About

Metafr provides a structured, declarative approach to construct HTML pages using an Abstract Syntax Tree (AST) in Rust. By abstracting away manual HTML string concatenation, it allows developers to build type-safe, component-driven user interfaces directly from the server.

Features

  • Declarative Routing: Easily define routes and map them to HTML documents leveraging Axum's powerful routing capabilities.
  • AST-Based Rendering: Construct pages robustly using a tree of Node elements and parameters.
  • Component System: Utilize built-in components like typography and scope to compose complex layouts easily.
  • Axum Integration: Take full advantage of the performance, ecosystem, and asynchronous runtime (Tokio) provided by Axum.

Getting Started

To use Metafr, simply define your pages, construct your DOM using the provided components, and pass them to the start function.

use metafr::components::{typography, scope};
use metafr::document::{Document, create_document};
use metafr::{Html, Page, get, start};

fn main() {
    let pages = vec![
        Page {
            path: "/".to_string(),
            method: get(|| async { 
                let home: Document = create_document(
                    scope::scope_create()
                    .set_children(vec![
                        typography::typography_create()
                            .set_text("Hello World!")
                            .build(),
                        typography::typography_create()
                            .set_text("Welcome to Metafr!")
                            .build()
                    ])
                    .build()
                );

                Html(home.render())
            }),
        }
    ];

    start(&pages);
}
